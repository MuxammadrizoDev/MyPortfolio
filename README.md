# Muxammadrizo.dev - Dynamic Portfolio & Admin Dashboard

A full-stack developer portfolio and custom Content Management System (CMS) built to showcase projects, manage client interactions, and provide real-time server analytics.

## Core Architecture
* **Backend:** Built with Python and FastAPI for high-performance REST APIs.
* **Database:** SQLite with SQLAlchemy ORM for lightweight, structured data management.
* **Real-Time Diagnostics:** WebSocket integration broadcasting live server CPU/RAM load and active visitor counts.
* **Frontend:** Zero-dependency vanilla HTML5, CSS3, and JavaScript featuring a matrix-inspired holographic UI.

## Advanced Features
* **Custom AI Co-Pilot:** Integrated Google Gemini (3.6 Flash) as an interactive site assistant to answer client questions and auto-generate/translate blog content into English, Uzbek, and Russian.
* **Secure Admin Gate:** 2FA authentication system using automated Gmail OTPs to lock down the management dashboard.
* **Dynamic Content Builder:** A visual HTML block builder allowing the owner to stack headers, text, and media seamlessly without touching the codebase.
* **Verified Reviews:** Telegram bot webhook integration to verify the authenticity of client reviews before displaying them on the public feed.

* ## How to make it work:
* **AdminPanel:** To go to admin panel write "/admin" in after site url like this http://link/admin/ .
* **Running:** write " uvicorn main:app --reload " in terminal.
